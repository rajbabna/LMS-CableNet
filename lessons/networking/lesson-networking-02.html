MOD 02

Module 2: Subnetting & CIDR Notation

Theme: Dividing Networks into Smaller Pieces

Learning Objectives

  • Explain what a subnet mask does and represent it in binary
  • Calculate network address, broadcast address, and usable host range
  • Read and write CIDR notation (e.g., /24, /25)
  • Apply the host formula: usable hosts = 2^(32 - prefix) - 2

Quiz: Decimal ↔ Binary (8:30–9:00)

Quick recall check from last week's homework before moving on.

Lecture Notes (9:00–10:30)

  • A subnet mask marks which bits of an IP address are "network" vs "host"
  • Common masks: 255.255.255.0 = /24, 255.255.255.128 = /25
  • In binary, mask bits are 1s for network, 0s for host

Usable hosts = 2^(32 - prefix) - 2 (minus 2 = network + broadcast)

  • /24 → 2^8 - 2 = 254
  • /26 → 2^6 - 2 = 62
  • Network address: all host bits set to 0
  • Broadcast address: all host bits set to 1
  • Usable host range: everything between network and broadcast
  • Never assign the network or broadcast address to a device

Lab 2A: Guided Subnet Calculation (10:45–11:30)

Given 192.168.1.0/24:

  • Network address → 192.168.1.0
  • Broadcast address → 192.168.1.255
  • Usable range → 192.168.1.1–192.168.1.254
  • Total usable hosts → 254 (formula: 2^8 - 2)

Lab 2B: Subdividing a Network (11:30–12:30)

Split 192.168.1.0/24 into 4 equal subnets for 4 departments (Accounting, Sales, Support, Backend), each needing ~60 hosts:

  1. We need 4 subnets → borrow 2 host bits (2^2 = 4)
  2. New prefix: /24 + 2 = /26
  3. Usable per subnet: 2^6 - 2 = 62 (fits 60)
  4. Block size = 64, subnets start at 0: - 192.168.1.0 /26 usable 192.168.1.1–192.168.1.62 - 192.168.1.64 /26 usable 192.168.1.65–192.168.1.126 - 192.168.1.128/26 usable 192.168.1.129–192.168.1.190 - 192.168.1.192/26 usable 192.168.1.193–192.168.1.254

Speed Drills (1:15–2:15)

  • Timed subnetting challenge (e.g., "Who can solve 10.0.0.0/25 fastest?")
  • Celebrate fast, correct answers to build confidence under pressure
  • Practice: given N hosts, choose the smallest prefix that fits
  • Quick-fire: readable /24–/30 host counts from memory

Check for Understanding

  1. What's the broadcast address for 192.168.1.0/24?
  2. How many usable hosts does a /26 network support?
  3. Write 255.255.255.192 in CIDR notation.
  4. Using the formula, how many usable hosts are in a /28?
