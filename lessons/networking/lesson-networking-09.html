MOD 09

Module 9: Final Assessment & Certification

Theme: Prove Your Expertise

Learning Objectives

  • Build and configure a complete network topology under timed conditions
  • Diagnose and fix multiple intentional faults in a broken network
  • Demonstrate theory retention across all Part 2 topics

Arrival (8:30–9:00)

Settle in, review final expectations for the day.

Practical Exam 1: Network Build & Configuration (9:00–10:00, 60 min)

Students build an assigned topology in Packet Tracer (e.g., "3 networks, 1 router, 12 total PCs"):

  • Configure all devices with correct IP addresses
  • Set up static routing between networks
  • Enable DHCP on one router
  • Verify: all devices can ping each other

Grading focus: correct topology, proper configuration, full connectivity

Break (10:00–10:30)

Practical Exam 2: Troubleshooting Challenge (10:30–11:30, 60 min)

Students receive a broken network with 3 intentional problems. They must:

  • Identify each of the 3 problems
  • Explain what's wrong
  • Fix each one and verify the fix
  • Document their findings

Possible fault types:

  • Wrong IP configuration
  • Missing default gateway
  • Incorrect routing
  • DNS not configured
  • Firewall blocking needed traffic

Break / Lunch (11:30–12:30)

Written Exam (12:30–1:15, 45 min)

  • 20 multiple choice questions (theory concepts)
  • 5 short-answer questions (subnetting, routing decisions)
  • 1 essay question (troubleshooting scenario)

Topics covered: IP addressing & subnetting, DHCP & DNS, static/dynamic routing, troubleshooting methodology, security basics

Lunch + Results Scoring (1:15–2:15)

Instructors score exams while students wait and celebrate finishing.

Results & Certificates (2:15–2:30)

  • Return graded exams with individual feedback
  • Award "Network Operations Graduate" certificates
  • Group photo and celebration
  • Discuss next steps:
  • CompTIA Network+ (30–40 more hours)
  • Cisco CCNA (60–80 more hours)
  • Available industry networking technician roles

Completion Pathways

After Part 2, students can:

  • Pursue CompTIA Network+ (industry-recognized)
  • Pursue Cisco CCNA
  • Seek networking technician roles directly
  • Specialize further in security, cloud, or wireless

Congratulations to all Network Operations graduates — and to everyone who has completed the full 100-hour, 18-Saturday program.
