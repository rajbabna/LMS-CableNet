MOD 04

Module 4: DHCP & DNS Configuration

Theme: Automatic IP Assignment & Name Resolution

Learning Objectives

  • Explain the DORA process for DHCP address assignment
  • Configure and observe DHCP behavior in Packet Tracer
  • Explain how DNS resolves names to IP addresses
  • Recognise the APIPA address (169.254.x.x) as "no DHCP answer"

Lecture Notes (9:00–10:30)

  • Automatically assigns IP addresses so devices don't need manual config
  • DORA process: 1. Discover — client broadcasts for a DHCP server 2. Offer — server offers an available IP 3. Request — client requests that specific IP 4. Acknowledge — server confirms the lease
  • IP pools have a defined range and a lease expiration time

If a device gets 169.254.x.x (APIPA self-assigned), it got no DHCP answer. Check in order:

  1. Is the DHCP server running and is its scope not exhausted?
  2. Is the device on the correct VLAN (Layer-2 path)?
  3. Is the DHCP relay / helper-address configured if the server is on another subnet?
  4. Is DHCP traffic (UDP 67/68) allowed by any firewall?
  • Translates human-readable names (www.example.com) into IP addresses
  • DNS servers hold records mapping names to addresses
  • Without DNS, users would need to memorize IP addresses for every site

Flow: browser asks local DNS → local DNS asks forwarders as needed → name resolves to an IP → traffic is sent to that IP. Troubleshooting hint: if ping by IP works but ping by name fails, the problem is DNS, not connectivity.

Lab 4A: Packet Tracer DHCP Lab (10:45–11:30)

  • Load the pre-made "DHCP network" file (1 router, 1 switch, 5 PCs)
  • Router acts as the DHCP server; PCs are set to DHCP mode
  • Observe: do PCs receive IP addresses automatically? (Yes)
  • Check assigned IPs and watch the DORA process play out in simulation

Lab 4B: Change DHCP Settings (11:30–12:30)

  • Modify the IP pool range on the router
  • Disable and re-enable one PC to trigger a new lease
  • Observe what IP address it receives, and discuss why DHCP matters at scale

Lab 4C: DNS Configuration (1:15–2:15)

  • Add a DNS server to the network
  • Configure domain names for devices
  • Ping devices by name instead of IP address
  • Compare: pinging by IP vs. by name

Real-world example: accessing a website.

  • Without DNS: typing 203.45.12.78 (hard to remember)
  • With DNS: typing www.example.com (easy!)

Check for Understanding

  1. What do the letters in "DORA" stand for?
  2. What happens if a device's DHCP lease expires?
  3. What problem does DNS solve for everyday internet use?
  4. What does getting 169.254.x.x tell you about DHCP?

Home Assignment

  • Reflect: how does DHCP make your life easier at home?
  • Find and screenshot your home router's DHCP settings
  • Write 2 sentences: "Why does DNS matter?"
  • Preview: next week is routing — how will that build on this?
