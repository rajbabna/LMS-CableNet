MOD 08

Module 8: Network Security Basics

Theme: Protecting Your Network

Learning Objectives

  • Explain why network security matters and name common threat types
  • Configure basic firewall rules and Access Control Lists (ACLs)
  • Explain the purpose of VLANs and basic network segmentation
  • Apply the CIA triad to a real security decision
  • Secure a home router with best-practice settings

Discussion (8:30–9:00)

Open with reflections on last week's troubleshooting successes before introducing security concepts.

Lecture Notes (9:00–10:30)

  • Confidentiality — only authorized people can read data
  • Integrity — data is accurate and unchanged
  • Availability — systems are up and usable when needed
  • Every security control exists to protect one or more of these
  • Common threats: viruses, hacking attempts, Denial of Service (DoS)
  • Phishing / social engineering — the #1 attack vector (the human is the weakest link; most breaches start with a phishing email, not a firewall)
  • Malware — viruses, worms, trojans, ransomware, spyware
  • Man-in-the-middle — eavesdropping or altering traffic between parties
  • Zero-day — attack on an unpatched vulnerability
  • Firewalls — hardware or software that filters traffic by rule
  • Access Control Lists (ACLs) — permit/deny rules applied to specific traffic types or addresses
  • Rule model (simplified): source IP:port → dest IP:port → action
  • Default should be DENY — allow only what's needed
  • Defense in depth — layering multiple security measures rather than relying on one (firewall + strong passwords + patching + antimalware)
  • Least privilege — give users only the access they need
  • Encryption (overview) — protects data in transit from being read if intercepted
  • VPN (concept only) — creates an encrypted tunnel over a public network
  • Patching — keep systems updated; most attacks exploit known holes

Lab 8A: Firewall Rules in Packet Tracer (10:45–11:30)

  • Load a network with a firewall device
  • Demo: firewall blocks traffic by default
  • Students create rules:
  • Allow HTTP traffic (port 80)
  • Block Telnet (port 23)
  • Test: allowed traffic passes, blocked traffic fails
  • Discuss why certain ports get blocked in real networks

Lab 8B: Access Control Lists (11:30–12:30)

  • Introduce the basic ACL concept: permit specific traffic, deny the rest
  • Configure a simple ACL
  • Test with ping (confirm allowed vs. denied traffic)

Lab 8C: Network Segmentation (1:15–2:00)

  • Introduce VLANs — separating departments on the same physical switch
  • Configure a VLAN and show that VLAN traffic is isolated
  • Discuss real-world use: separating student vs. staff networks
  • Note: VLANs = security AND performance (broadcast containment)

Security Discussion (2:00–2:15)

  • Password strength & policies (long passphrases + MFA)
  • Changing default passwords (routers ship with known credentials)
  • Role-based access control (least privilege)
  • Monitoring & alerts
  • Securing a home router: change defaults, enable WPA2/WPA3 (never WEP), disable remote admin, update firmware

Wrap-Up (2:15–2:30)

Security is everyone's responsibility, and these concepts commonly come up in job interviews. Preview: final exam next week.

Check for Understanding

  1. What's the difference between a firewall rule and an ACL?
  2. Why would a company separate students and staff onto different VLANs?
  3. Name one reason default passwords are a security risk.
  4. What are the three parts of the CIA triad, and give an attack on each?
