MOD 07

Module 7: Troubleshooting Practicals — Broken Networks

Theme: Detective Work — Find & Fix Problems

Learning Objectives

  • Apply the troubleshooting framework to realistic broken-network scenarios
  • Diagnose and fix IP, gateway, routing, and DNS misconfigurations
  • Design a troubleshooting scenario for a peer to solve

Setup (8:30–9:00)

Review last week's tools, then load pre-made broken networks in Packet Tracer for the session's scenarios.

Scenario 1: Wrong IP Configuration (9:00–9:45)

  • Network: 4 PCs, 1 switch
  • Problem: 2 PCs have IPs on the wrong subnet
  • Students must: identify the problem PC, determine the correct IP, fix it, and verify with ping

Scenario 2: Missing Default Gateway (9:45–10:30)

  • Network: 2 switches, 1 router, 8 PCs
  • Symptom: some PCs can't reach the other network
  • Troubleshooting flow: 1. Ping local device — works 2. Ping remote device — fails 3. Check gateway configuration — missing! 4. Add the gateway, then verify

Break (10:30–10:45)

Scenario 3: Routing Issue (10:45–11:30)

  • Multi-network topology with misconfigured routes
  • Students analyze the routing table, identify the incorrect route, fix it, and verify with tracert

Scenario 4: DNS Problem (11:30–12:30)

  • Network with a DNS server
  • Symptom: ping by IP works, ping by name fails
  • Students diagnose using nslookup, check DNS configuration, and reconfigure as needed

Lunch (12:30–1:15)

Scenario 5: Student-Designed Challenge (1:15–2:15)

  • Pairs build a broken network for another pair to solve
  • Add one "intentional problem," then swap
  • The other pair must find and fix it — competitive but collaborative
  • Celebrate successful fixes

Wrap-Up (2:15–2:30)

Reinforce: "Real networks have these exact issues — your skills are already valuable." Preview: security concepts next week.

Check for Understanding

  1. If local pings work but remote pings fail, what should you check first?
  2. How would you confirm a DNS problem vs. a routing problem?
  3. Describe one intentional problem you'd design for a peer to solve.

Home Assignment

  • Document one troubleshooting scenario: problem, steps taken, solution
  • Reflect: "What was hardest to diagnose, and why?"
  • Prepare for security concepts next week
