MOD 05

Module 5: Routing Fundamentals

Theme: Connecting Multiple Networks

Learning Objectives

  • Explain what routing is and why it's needed between networks
  • Configure static routes in Packet Tracer
  • Read and interpret a router's routing table

DHCP Quiz (8:30–9:00)

Quick recall check before moving into new material.

Lecture Notes (9:00–10:30)

  • Routing moves traffic between different networks (switching only moves traffic within one network)
  • A routing table lists known destination networks and how to reach them
  • Default gateway — where a device sends traffic when the destination isn't on its local network
  • Next-hop routing — a route often just points to the next router in the path, not the final destination directly
  • Static — manually configured by an administrator; simple, predictable, but doesn't adapt automatically
  • Dynamic — routers exchange information automatically using protocols like RIP, OSPF, or EIGRP (overview only in this course — not hands-on)

Lab 5A: Multi-Network Setup (10:45–11:30)

  • Load the pre-made "Two networks, one router" file:
  • Network A: 192.168.1.0/24 (5 PCs + switch)
  • Network B: 192.168.2.0/24 (5 PCs + switch)
  • A single router connects both
  • Discuss: can A talk to B yet? (Not yet!)

Lab 5B: Configure Static Routes (11:30–12:30)

  • On the router, add a static route: "to reach 192.168.2.0/24, go via the router's port 1"
  • Add the reverse route on the other side
  • Test: PCs in Network A can now ping PCs in Network B
  • Celebrate the first successful routing configuration

Lab 5C: Analyze Routing Tables (1:15–2:15)

  • View the router's routing table and explain what each entry means
  • Discuss: "How did the packet actually get there?"
  • Add more routes and observe the table change
  • Experiment: remove a route and observe what breaks

Watch a packet travel between networks — leaving Network A through the router, and arriving in Network B.

Wrap-Up (2:15–2:30)

Routing is what enables the internet at scale — "your data crosses many routers to reach a site like YouTube." Preview: troubleshooting these networks is next.

Check for Understanding

  1. What's the difference between switching and routing?
  2. What is a default gateway used for?
  3. What breaks if a static route is missing or misconfigured?

Home Assignment

  • Draw a 3-network topology on paper
  • Identify what static routes would be needed to connect them
  • Study: what happens to traffic if routing is misconfigured?
  • Prepare for troubleshooting next week
