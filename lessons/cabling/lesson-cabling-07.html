MOD 07

Module 7: Device Overview & Packet Tracer Intro

Theme: Where Your Cables Connect

Learning Objectives

  • Describe the role of switches, routers, and modems in a network
  • Identify ports, LEDs, and cable connections on real equipment
  • Build and test a simple 2-device network in Cisco Packet Tracer
  • Explain the Layer-2 vs Layer-3 difference between switch and router

Quiz on Cabling Standards (8:30–9:00)

Quick recall check before moving into new material.

Lecture: Network Devices (9:00–10:30)

  • Switches — connect devices within a network (Layer 2), forward traffic based on MAC addresses. Maintain a MAC address table so each port can carry full bandwidth at once.
  • Routers — connect different networks together (Layer 3), forward traffic based on IP addresses. Choose the best path via a routing table.
  • Modems — connect a local network to an ISP's external connection
  • Network cards (NICs) — where cables physically plug into a device
  • Ports & speeds — 100 Mbps (Fast Ethernet) vs 1 Gbps (Gigabit) ports
  • Show real equipment or photos to make ports and LEDs tangible

Rule of thumb: Switch = MAC, "inside" the network. Router = IP, "between" networks. A typical home "router" is actually a router + switch + wireless access point combined.

Lab 7A: Device Identification (10:45–11:30)

  • Hands-on inspection of real switches/routers
  • Identify ports, status LEDs, and cable types in use
  • Discuss: how many devices/cables can a given switch support?
  • Trace physical cables through a real (or classroom) network setup
  • Count how many ports are 100 Mbps vs 1 Gbps on each device

Lab 7B: Intro to Packet Tracer (11:30–12:30)

  1. Launch Cisco Packet Tracer
  2. Open the pre-made "Simple 2-device network" file
  3. Drag 2 PCs onto the canvas
  4. Connect them with a straight-through cable
  5. Observe the simulated packet flow
  6. Try it again through a switch (3+ PCs) and watch the switch forward

Packet Tracer Lab Continued (1:15–2:15)

  • Assign IP addresses to both PCs
  • Ping between them and watch the simulation animate the packet
  • Discuss: "Where is the data actually going?"
  • Compare: two PCs on the same subnet (switch handles it) vs two PCs on different subnets (a router is required) — a preview of Part 2
  • Connect it back to Module 3–6: "The cable you crimped is what makes this possible."

Wrap-Up (2:15–2:30)

Reinforce the link between physical cabling and logical connectivity. Preview: "Saturday 8 is final assessment prep."

Check for Understanding

  1. What's the functional difference between a switch and a router?
  2. What device connects your home network to your ISP?
  3. In Packet Tracer, what did assigning IP addresses allow you to do?
  4. Which layer does a switch operate at, and what does it forward on?

Home Assignment

  • Finish the Packet Tracer file at home if possible
  • Prepare final crimped cables for Saturday 8
  • Memorize the T568B order — it will be tested
  • Review all lab notes from Modules 1–7
