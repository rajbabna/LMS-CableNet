MOD 05

Module 5: Crimping Practice Marathon & Testing Intro

Theme: Build Muscle Memory

Learning Objectives

  • Crimp cables with increasing consistency (target: 5+ this session)
  • Operate a cable tester and interpret its results
  • Diagnose which pin(s) failed and begin connecting failures to causes
  • Read a tester pattern and map it to a termination mistake

Quick Q&A on Technique (8:30–9:00)

Revisit last week's grip/pressure lessons before diving back in.

Lecture: How a Cable Tester Works (9:00–9:15)

  • The tester sends a signal down each pin in turn and lights an LED per pin on the remote unit
  • Lit LED in order = that pin is wired and continuous
  • No light = broken or miswired pin (open)
  • Light on the wrong pin = a crossed/shorted pair (order error)
  • Read the tester end-to-end: the pattern tells you the kind of fault, not just "pass/fail"

Intensive Crimping Practice (9:15–10:30)

  • Students bring pre-measured cables from home
  • Each student aims for 5+ cables this session
  • Instructor circulates, correcting form in real time — focus areas:
  • Wire insertion depth (jacket past the strain-relief barb)
  • Even crimp pressure (one firm squeeze to ratchet release)
  • Full connector seating (8 pins show copper contact)
  • Faster finishers assist slower students (peer teaching reinforces their own technique)

Continued Crimping + Testing Introduction (10:45–12:30)

  • Continue crimping as needed
  • Introduce the cable tester:
  • A light per pin means that pin is wired correctly
  • No light = broken or miswired pin
  • Test immediately after each crimp — build the habit: Crimp → Test → Read → Fix
  • Each student tests their own cables for the first time

Testing Lab (1:15–2:15)

  • All students test the cables made in Saturday 4
  • Record results: which pins work, which fail, per cable
  • Guided failure analysis — ask diagnostic questions:
  • "Why did pin 3 fail?"
  • "Are you inserting the wires fully?"
  • "Is your crimp pressure even across all pins?"
  • Map each tester pattern to the mistake table from Module 3:
  • All 8 pass → good
  • 4 of 8 fail on one side → uneven pressure / shallow insertion
  • Crossed pins → wire order error
  • No lights at all → connector not seated / wrong end tested
  • Troubleshoot as a group, cable by cable

Wrap-Up: Homework Challenge (2:15–2:30)

Frame remaining failures as a discussion topic for home, not a failure — this sets up next week's troubleshooting-focused module. Celebrate first full-PASS cable per student.

Check for Understanding

  1. What does a lit LED on a cable tester pin indicate?
  2. If 4 consecutive pins fail on the same side, what's the likely cause?
  3. What's the difference between a testing failure and a crimping failure?
  4. If a tester shows a light on the wrong pin, what fault does that mean?

Home Assignment

  • Inspect your tested cables — which failed, and why?
  • Write 2–3 sentences per failed cable explaining the likely issue
  • Watch a troubleshooting video on failed crimps
  • Prepare 4 more blank cables for Saturday 6
