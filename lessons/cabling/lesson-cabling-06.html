MOD 06

Module 6: Troubleshooting & Fixing Cables

Theme: Why Cables Fail & How to Fix Them

Learning Objectives

  • Diagnose common crimping failure patterns from tester results
  • Remake a failed cable successfully
  • Build a repeatable "crimp → test → learn" feedback loop
  • Explain the troubleshooting method (define → test → fix → verify)

Review of Homework Failures (8:30–9:00)

Open discussion: what patterns did students notice in their own failed cables? Surface common issues before the lecture.

Lecture: Common Crimping Failures (9:00–10:30)

Failure Pattern (tester)Likely Cause
4 of 8 pins failUneven crimping pressure
One entire side failsWires not fully inserted on that side
Random, scattered pins failBent or damaged wires before crimping
Connector physically damagedTool misuse or wrong tool
Crossed/out-of-order lightsWire color order error (verify T568B)
No lights at allConnector not seated / tested wrong end

Cover prevention strategies for each pattern.

  1. Define the problem — what exactly fails? (which pins)
  2. Gather info — run the tester, record the pattern
  3. Hypothesize — which mistake matches that pattern?
  4. Test the fix — re-terminate, re-test immediately
  5. Verify — the cable passes AND stays passing under slight flex/pull
  6. Document — note the cause so the same mistake is caught faster next time

> This same 6-step loop is the backbone of Part 2's network troubleshooting > modules — it applies far beyond cables.

Lab 6A: Diagnosing Failures (10:45–11:30)

  • Examine last week's failed cables under a magnifier
  • Identify the specific issue per cable using the failure-pattern table
  • Compare good vs bad crimps side by side
  • Look through the transparent plug: can you SEE the mistake before testing?

Lab 6B: Remaking Failed Cables (11:30–12:30)

  • Take a failed cable, strip it back
  • Re-crimp with corrected technique
  • Test immediately
  • Goal: fix 3 failed cables this session

Continued Practice & Testing (1:15–2:15)

  • More crimping with new blank cables
  • Test immediately after each crimp — reinforce the feedback loop: Crimp → Test → Get result → Learn → Crimp better
  • By this point, quality should be visibly improving
  • Quick pull-test habit: after a pass, gently pull the plug — if the clip holds and the cable stays live, the strain relief engaged

Wrap-Up (2:15–2:30)

Track and celebrate progress — count working cables per student. Preview: "By Saturday 7, we start certifying cables."

Check for Understanding

  1. If a cable fails on 4 pins clustered on one side, what's the likely fix?
  2. Why is immediate testing after crimping more effective than testing in a batch later?
  3. Describe the crimp-test-learn feedback loop in your own words.
  4. What does a "crossed" tester pattern mean, and how do you prevent it?

Home Assignment

  • Bring 4 more blank cables
  • Target: 8 total working cables by Saturday 7
  • Practice at home if tools are available
  • Study: "What makes a good crimp?" — be ready to explain it
