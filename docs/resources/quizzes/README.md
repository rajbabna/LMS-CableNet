# Cable&Net Courses — Module Quizzes

Quizzes grouped by **learning phase** for both courses. Each quiz maps to one
module and is grounded in the resources in `docs/resources/` plus the authored
module files in `docs/cablenet-courses-bundle/`.

Phases follow the grouping defined in
`docs/ui/Cable_Net_Page_Restructure_Recommendations.md` (Option 1: tabbed
phase view).

## Format

Each quiz file follows a consistent structure:

1. **Phase banner + module link** — which module/phase it serves
2. **Multiple Choice** (with single correct answer, lettered)
3. **Short Answer** — recall/explain
4. **Answer Key** — correct answer + source reference (resource file + section)

Quizzes are designed as **instructor-facing** banks: pull questions for
openers, wrap-ups, or the written assessment; adapt count/difficulty per
class. Answers reference the exact resource section so any question can be
traced back to its source.

> Cross-references: `docs/resources/*` (source material),
> `docs/cablenet-courses-bundle/*.md` (authored modules).
