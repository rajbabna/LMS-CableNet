## Multiple Choice

**1.** When one ENTIRE side of the tester fails, the likely cause is:

- A. Uneven crimp pressure
- B. Wires not fully inserted on that side
- C. Wrong cable category
- D. Shielding problem

**2.** Random, scattered pins failing is most likely due to:

- A. Wires in wrong color order
- B. Bent or damaged wires before crimping
- C. Too much untwisting
- D. A good termination

**3.** What is the FIRST step of the 6-step troubleshooting method?

- A. Test the fix
- B. Hypothesize
- C. Define the problem
- D. Document

**4.** A "crossed/out-of-order" tester pattern means:

- A. The cable is too long
- B. A wire color order error — verify T568B
- C. The tester is broken
- D. Uneven pressure

**5.** After a cable passes, what quick pull-test verifies the strain relief engaged?

- A. Twist the cable tightly
- B. Gently pull the plug — if the clip holds and it stays live, good
- C. Bend it at 90°
- D. Re-crimp it

**6.** Which feedback loop best builds reliable crimping?

- A. Crimp → Test → Get result → Learn → Crimp better
- B. Test → Fix → Repeat
- C. Crimp all → test batch → fix → forget
- D. Guess → check

---

## Short Answer

**7.** Why is immediate testing after crimping more effective than testing in a batch later?

**8.** Describe the crimp-test-learn feedback loop in your own words.

**9.** If a cable fails on 4 pins clustered on one side, what is the likely fix?

---

## Answer Key

1. **B** — One entire side fails = wires not fully inserted on that side (module §Failure Pattern table).
2. **B** — Random scattered pins = bent or damaged wires before crimping (module §Failure Pattern table).
3. **C** — Define the problem (module §The Troubleshooting Method).
4. **B** — Crossed/out-of-order = wire color order error; verify T568B (module §Failure Pattern table).
5. **B** — Gentle pull-test; holds + stays live = strain relief engaged (module §Continued Practice).
6. **A** — Crimp → Test → Get result → Learn → Crimp better (module §Continued Practice).
7. Immediate testing keeps cause-and-effect tight so you know which crimp produced which result; batching loses that connection (module §Lab 6B, §Continued Practice).
8. Crimp a cable, test it, read the result, apply what the result teaches to the next crimp — a repeating feedback loop that sharpens technique (module §Continued Practice).
9. Likely uneven/shallow on that side — re-strip, re-seat wires fully and evenly, re-crimp, then test again (module §Lecture + §Lab 6B).

> Difficulty: recall (Q1–6), explain/apply (Q7–9).
