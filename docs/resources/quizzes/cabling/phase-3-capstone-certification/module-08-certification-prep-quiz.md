## Answer Key

1. **B** — CCST Networking (module §The Certification Path).
2. **B** — Networking Basics (22 h) is a feeder (module §Certification Path, resource §1).
3. **B** — Help desk + troubleshooting practice, security basics, access control (resource §1).
4. **C** — Networking: 9/9 modules fully covered (resource §4).
5. **B** — Modules 03–05 are hands-on termination covered by our authored resources (resource §4).
6. **B** — 22 + 14 + 12 = 48 hours (resource §1).
7. Strip jacket (10–13 mm) → untwist/arrange T568B → keep twist short → trim flush → insert past the barb → crimp evenly to ratchet release → test (module §Final Practice Lab, field guide §3).
8. Practical crimping, cable testing/verification, and a written assessment (module-09 structure; module §Final Q&A).
9. Networking Basics (22 h), Network Addressing and Basic Troubleshooting (14 h), Network Support and Security (12 h) (module §Certification Path, resource §1).
