## Short Answer

**7.** Write the T568B pin order from memory.

**8.** Explain the difference between a straight-through and a crossover cable.

**9.** Name three of the four common reasons cables fail.

---

## Answer Key

1. **B** — 1 straight-through + 1 crossover (module §Practical Exam Part A).
2. **D** — Layer 1 (Physical); the course lives mostly at Layer 1 (module §Lecture Notes).
3. **B** — Static route configuration is Part 2; the Part 1 written test covers pin order, straight/crossover, failure causes, OSI layer, device ID (module §Written Assessment).
4. **C** — All 8 conductors for 1 Gbps; only 4 (pairs 1-2, 3-6) for 100 Mbps (module-03 §Real Pair Circuits).
5. **D** — All three are termination mistakes from module-03/06 failure tables.
6. **B** — Part 2, CompTIA A+ Hardware, or entry-level cabling/tech roles (module §Completion Pathways).
7. W-Orange, Orange, W-Green, Blue, W-Blue, Green, W-Brown, Brown.
8. Straight-through uses the same T568A or T568B on both ends (PC↔switch); crossover swaps to T568A on one end (PC↔PC, switch↔switch). Auto-MDIX makes crossover rare today (module-03 §Straight-Through vs Crossover).
9. Wrong wire order, jacket not past the barb, untwisted too far, trim not flush, uneven pressure, or shallow insertion (module-03/04/06).

> Difficulty: consolidation (Q1–6), memory/apply (Q7–9).
