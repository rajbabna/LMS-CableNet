MOD 03

Module 3: Packet Tracer — IP Configuration & Connectivity

Theme: Theory Meets Simulation

Learning Objectives

  • Build a simple switched network in Cisco Packet Tracer
  • Manually configure static IP addresses on end devices
  • Test and verify connectivity using ping

Demonstration: Simple Network Build (9:00–10:30)

  • Instructor builds a 4-PC network with 1 switch, narrating each step
  • Show how to add devices and connect them with straight-through cables
  • Everyone follows along on their own machine

Lab 3A: Students Build the Network (10:45–11:30)

  • Each student (or pair) builds the same network: 4 PCs, 1 switch, 5 straight-through cables
  • Instructor checks progress as students work

Lab 3B: Assign IP Addresses (11:30–12:30)

Each student configures IP addresses manually:

DeviceIP Address
PC1192.168.1.1/24
PC2192.168.1.2/24
PC3192.168.1.3/24
PC4192.168.1.4/24

Lab 3C: Test Connectivity (1:15–2:15)

  • Ping from PC1 to PC2
  • Watch simulation mode to see packets travel
  • Discuss: why does it work?
  • Try pinging all device combinations
  • Observe how the switch learns MAC addresses over time

This network runs on the same crimped cables from Part 1 — connecting the physical skills from Module 1–9 (Part 1) to the logical configuration skills in this course.

Wrap-Up (2:15–2:30)

Save work, preview next week: DHCP will make IP assignment automatic.

Check for Understanding

  1. What must match for two PCs on the same subnet to ping each other?
  2. What does "simulation mode" let you observe in Packet Tracer?
  3. How does a switch learn which MAC address is on which port?

Home Assignment

  • Repeat the same Packet Tracer lab at home if you have access
  • Screenshot your working network
  • Write 3 sentences: "How does IP addressing work?"
  • Prepare for DHCP & DNS next week
